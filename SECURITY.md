# Security policy

Brier is a play-money exchange, but its accounts, sessions and order path are built to the standard of a real venue. Reports are welcome.

## Reporting a vulnerability
- Report privately through [GitHub's private vulnerability reporting](https://github.com/anamankev/brier/security/advisories/new). Do not open a public issue.
- Include what you found, how to reproduce it, and what an attacker could do with it.
- You will get an answer within 7 days.

## Scope
- In scope: the live site at https://playbrier.duckdns.org and the code in this repository.
- Out of scope: denial-of-service testing, social engineering, and attacks on Oracle Cloud, GitHub or the data providers.

## Testing safely
- Use your own accounts only.
- Never read, change or delete another user's data.
- Stop and report as soon as you can show the problem.
